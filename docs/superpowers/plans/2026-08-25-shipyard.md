# Shipyard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A zero-dependency local Node web dashboard (`shipyard`) that shows every in-flight flow — /ship runs, open PRs, Linear tasks, ambient branches, Claude-session activity — grouped by attention, with docs/PR one click away; plus a one-line /ship skill change adding per-phase timestamps.

**Architecture:** One Node process: collectors observe the filesystem/git/gh/Linear, `merge.js` resolves findings into unified Flow cards (stable identity, dedupe, needs-you truth table), `archive.js` mirrors live ship state on every scan so history survives post-merge worktree deletion, and an HTTP server (token + Host-checked) feeds a vanilla single-page UI.

**Tech Stack:** Node ≥ 20 builtins only (ESM), `node --test`, vanilla HTML/JS/CSS. External CLIs consumed read-only: `git`, `gh`. Linear via GraphQL `fetch`.

**Spec:** `docs/superpowers/specs/2026-08-25-shipyard-design.md` (claude-config). Visual reference: `docs/superpowers/specs/2026-08-25-shipyard-board-mockups.html` — the "Option B" section is the target look; copy its CSS custom-property tokens (light+dark) and chip/card/pipe classes.

## Global Constraints

- Node `>= 20`; **zero runtime dependencies** — `node:` builtins only, no build step, and `node bin/shipyard` must work on a bare clone with no `npm install`. `devDependencies` are allowed **only** for quality tooling (eslint, prettier); nothing in `lib/`, `server.js`, `bin/`, or `public/` may import from `node_modules`.
- ESM everywhere (`"type": "module"`).
- No database. Persistence = config JSON, archive dir, `localStorage` (UI prefs only).
- Server binds `127.0.0.1` only. Every non-GET route requires header `X-Shipyard-Token`. Every route rejects `Host` other than `127.0.0.1:<port>` / `localhost:<port>` with 403.
- `openCommand` is never settable via HTTP; child processes only via `execFile` argv arrays, never shell strings.
- Shipyard never writes to a worktree, repo, GitHub, or Linear.
- Collectors fail soft: errors become source-health entries / `degraded` chips, never a blank board.
- Conventional commits. Tasks 2+ happen in the new repo `github.com/yaniv120892/shipyard` (public). Task 1 happens in `claude-config`.
- All timestamps ISO-8601 UTC strings in data, epoch ms in memory where compared.
- Every task ships as its own PR through the delivery workflow below — the per-task "Commit" steps feed that cycle, they don't end it.

## Per-task delivery workflow — every task ships as its own PR

This replaces each task's final "Commit" step (the commit itself stays; what
follows it changes). Nothing merges to `main` without going through this cycle.

1. **Branch per task**: `git checkout -b task/NN-<short-slug>` from the latest
   `main` (for Task 1, branch in claude-config — its repo rule is that changes
   ship via PR to main).
2. **Do the task's steps as written** — tests first, commit with the task's
   conventional-commit message.
3. **Polish gate** (before opening the PR), using the claude-config plugins and
   rules — the repo is installed as a plugin marketplace, so these are the
   skills to invoke, not descriptions to imitate:
   - **REQUIRED SUB-SKILL `prune-comments`**, scoped to this branch's diff —
     strip redundant comments; where a comment props up a bad name, rename
     instead of deleting.
   - **`/simplify`** — reuse/simplification/altitude cleanups on the changed code.
   - **`/code-review` (medium)** — fix confirmed findings; re-run until it
     comes back clean or only disputed nits remain (note those in the PR).
   - **Rules alignment**: re-read claude-config `shared-rules.md` and
     `rules/code.md` (all shipyard code is JS, so `code.md` applies) plus the
     shipyard repo's own `CLAUDE.md`; fix violations — naming, guard clauses,
     error handling, comment policy, conventional commits.
   - **Full quality suite green**: `npm run check` (syntax/boot — the no-build
     stand-in for a build step) && `npm run lint` && `npm run format:check`
     (run `npm run format` first if it complains) && `npm test`; for UI-touching
     tasks also a demo-mode smoke check. These are the same scripts the
     claude-config `pre-push-quality-gate` hook detects, so pushes get the gate
     automatically.
4. **Open the PR** — **REQUIRED SUB-SKILL `creating-prs`**. Title is a valid
   conventional commit (squash target); description covers what/why, the test
   evidence, and anything the polish gate changed.
5. **Merge (squash) before starting any dependent task.** The independent
   groups (Tasks 7–10; Tasks 17–18) may be open as parallel PRs; everything
   else is sequential.

**Addition to Task 2:** the scaffold also creates `CLAUDE.md` in the shipyard
repo — commands (`npm test`, `node bin/shipyard`, demo mode), the zero-dependency
constraint, the security invariants (token/Host/execFile/openCommand-file-only),
and the module dependency direction (`lib/` never imports `server.js` or
`public/`). This is the anchor every later polish gate aligns against, and it
gets updated in any PR that changes what it states.

import http from 'node:http';

export function createServer({ token, version, engine, config }) {
  const server = http.createServer(async (req, res) => {
    const url = new URL(req.url, 'http://127.0.0.1');
    try {
      if (req.method === 'GET' && url.pathname === '/api/health') {
        return json(res, 200, { name: 'shipyard', version });
      }
      json(res, 404, { error: 'not found' });
    } catch (err) {
      json(res, 500, { error: err.message });
    }
  });
  server.shipyard = { token, engine, config };
  return server;
}

export function startServer(server, port) {
  return new Promise((resolve, reject) => {
    server.once('error', reject);
    server.listen(port, '127.0.0.1', () => resolve(server.address().port));
  });
}

export function json(res, status, body) {
  res.writeHead(status, { 'Content-Type': 'application/json; charset=utf-8' });
  res.end(JSON.stringify(body));
}
```

import crypto from 'node:crypto';

export function normalizeRemoteUrl(url) {
  if (!url) return null;
  let u = url.trim().replace(/\.git\/?$/i, '');
  if (/^https?:\/\//i.test(u)) {
    const parsed = new URL(u);
    u = `${parsed.hostname}/${parsed.pathname.replace(/^\/+|\/+$/g, '')}`;
  } else {
    const m = u.match(/^(?:ssh:\/\/)?(?:[\w.-]+@)?([\w.-]+)[:/](.+)$/);
    if (m) u = `${m[1]}/${m[2].replace(/^\/+|\/+$/g, '')}`;
  }
  return u.toLowerCase();
}

export function repoKey({ remoteUrl, mainPath }) {
  return normalizeRemoteUrl(remoteUrl) ?? `path:${mainPath}`;
}

export function runId({ repoKey, branch, birthIso }) {
  return crypto.createHash('sha256')
    .update(`${repoKey}\n${branch}\n${birthIso}`)
    .digest('hex').slice(0, 16);
}

const TICKET_RE = /\b([A-Za-z][A-Za-z0-9]+-\d+)\b/;

export function extractTicket(text) {
  const m = TICKET_RE.exec(text ?? '');
  return m ? m[1].toUpperCase() : null;
}
```

Note: `extractTicket` over-matches strings like `release-2024`; that is safe because callers (Task 11) only join a ticket that exists in the tracker's issue list.

```js
import fs from 'node:fs';
import path from 'node:path';
import crypto from 'node:crypto';

export function isInside(root, target) {
  let realRoot, realTarget;
  try {
    realRoot = fs.realpathSync(root);
    realTarget = fs.realpathSync(target);
  } catch {
    return false;
  }
  const rel = path.relative(realRoot, realTarget);
  return rel === '' || (!rel.startsWith('..') && !path.isAbsolute(rel));
}

export function createToken() {
  return crypto.randomBytes(24).toString('hex');
}
```

import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';

export const DEFAULTS = Object.freeze({
  port: 4111,
  roots: ['~/Develop', '~/dev', '~/Projects', '~/code'],
  maxDepth: 6,
  activityThresholdMinutes: 10,
  networkTtlSeconds: 90,
  openCommand: 'cursor',
  ignore: [],
  history: { maxEntries: 200, maxAgeDays: 90 },
  tracker: { provider: 'linear', workspace: 'yaniv-daye-personal', teams: [], projects: [], states: [], cap: 50 },
});

export const USER_EDITABLE = ['roots', 'ignore', 'tracker', 'activityThresholdMinutes', 'networkTtlSeconds', 'history'];

export function configPath(home) {
  return path.join(home, '.claude', 'shipyard.config.json');
}

function expandHome(p, home) {
  return p.startsWith('~') ? path.join(home, p.slice(1)) : p;
}

export function loadConfig({ home = os.homedir() } = {}) {
  const file = configPath(home);
  let raw = null;
  try { raw = JSON.parse(fs.readFileSync(file, 'utf8')); } catch { /* absent or invalid: bootstrap */ }
  const created = raw === null;
  const config = { ...DEFAULTS, ...raw,
    history: { ...DEFAULTS.history, ...raw?.history },
    tracker: { ...DEFAULTS.tracker, ...raw?.tracker } };
  const missingRoots = [];
  config.roots = (raw?.roots ?? DEFAULTS.roots)
    .filter((r) => {
      const abs = expandHome(r, home);
      if (fs.existsSync(abs)) return true;
      missingRoots.push(r);
      return false;
    })
    .map((r) => expandHome(r, home));
  return { config, path: file, created, missingRoots };
}

export function saveUserConfig(partial, { home = os.homedir() } = {}) {
  const file = configPath(home);
  let existing = {};
  try { existing = JSON.parse(fs.readFileSync(file, 'utf8')); } catch { /* first save */ }
  for (const key of USER_EDITABLE) {
    if (key in partial) existing[key] = partial[key];
  }
  fs.mkdirSync(path.dirname(file), { recursive: true });
  fs.writeFileSync(file, JSON.stringify(existing, null, 2) + '\n');
  return existing;
}
```

import fs from 'node:fs/promises';
import { existsSync } from 'node:fs';
import path from 'node:path';
import { execFile } from 'node:child_process';
import { repoKey } from './ids.js';

const SKIP = new Set(['node_modules', 'dist', 'build', 'out', 'target', 'vendor',
  '.next', '.venv', 'venv', '__pycache__', 'coverage', '.cache', '.terraform']);

export function gitP(args, cwd) {
  return new Promise((resolve) => {
    execFile('git', args, { cwd, timeout: 8000, maxBuffer: 4 * 1024 * 1024 },
      (err, stdout) => resolve(err ? null : stdout.toString().trim()));
  });
}

function classifyForge(remoteUrl) {
  if (!remoteUrl) return 'none';
  if (remoteUrl.includes('github.com')) return 'github';
  if (remoteUrl.includes('gitlab')) return 'gitlab';
  return 'other';
}

function parseWorktrees(porcelain) {
  const worktrees = [];
  let current = null;
  for (const line of porcelain.split('\n')) {
    if (line.startsWith('worktree ')) current = { path: line.slice(9), branch: null };
    else if (line.startsWith('branch ') && current) current.branch = line.slice(7).replace('refs/heads/', '');
    else if (line === '' && current) { worktrees.push(current); current = null; }
  }
  if (current) worktrees.push(current);
  return worktrees;
}

async function walkForGitDirs(root, maxDepth) {
  const found = [];
  const queue = [{ dir: root, depth: 0 }];
  while (queue.length) {
    const { dir, depth } = queue.shift();
    if (existsSync(path.join(dir, '.git'))) { found.push(dir); continue; }
    if (depth >= maxDepth) continue;
    let entries = [];
    try { entries = await fs.readdir(dir, { withFileTypes: true }); } catch { continue; }
    for (const e of entries) {
      if (!e.isDirectory() || SKIP.has(e.name)) continue;
      if (e.name.startsWith('.') && e.name !== '.worktrees') continue;
      queue.push({ dir: path.join(dir, e.name), depth: depth + 1 });
    }
  }
  return found;
}

export async function discoverRepos(roots, { maxDepth = 6 } = {}) {
  const gitDirs = (await Promise.all(roots.map((r) => walkForGitDirs(r, maxDepth)))).flat();
  const byMainPath = new Map();
  for (const dir of gitDirs) {
    const porcelain = await gitP(['worktree', 'list', '--porcelain'], dir);
    if (!porcelain) continue;
    const worktrees = parseWorktrees(porcelain);
    const mainPath = worktrees[0]?.path;
    if (!mainPath || byMainPath.has(mainPath)) continue; // linked worktree of a known repo
    const remoteUrl = await gitP(['remote', 'get-url', 'origin'], mainPath);
    const head = await gitP(['symbolic-ref', 'refs/remotes/origin/HEAD'], mainPath);
    byMainPath.set(mainPath, {
      key: repoKey({ remoteUrl, mainPath }),
      name: path.basename(mainPath),
      mainPath, remoteUrl,
      forge: classifyForge(remoteUrl),
      defaultBranch: head ? head.replace('refs/remotes/origin/', '') : 'main',
      worktrees,
    });
  }
  return [...byMainPath.values()];
}

import fs from 'node:fs';
import path from 'node:path';

const DOC_NAMES = ['scope.md', 'plan.md', 'proof-of-work.md'];
const FAIL_LIMIT = 3;

export function parseHistory(history) {
  if (!Array.isArray(history)) return [];
  return history.map((entry) =>
    typeof entry === 'string'
      ? { phase: null, at: null, note: entry }
      : { phase: entry.phase ?? null, at: entry.at ?? null, note: entry.note ?? null });
}

function listDocs(shipDir) {
  const docs = [];
  const push = (name, file) => {
    try {
      const st = fs.statSync(file);
      docs.push({ name, rel: name, mtimeMs: st.mtimeMs });
    } catch { /* absent */ }
  };
  for (const name of DOC_NAMES) push(name, path.join(shipDir, name));
  try {
    for (const f of fs.readdirSync(path.join(shipDir, 'reports'))) {
      if (f.endsWith('.md')) push(`reports/${f}`, path.join(shipDir, 'reports', f));
    }
  } catch { /* no reports yet */ }
  return docs;
}

export function createShipCollector() {
  const cache = new Map(); // shipDir -> { state, failCount }
  return {
    read(shipDir) {
      const stateFile = path.join(shipDir, 'state.json');
      const entry = cache.get(shipDir) ?? { state: null, failCount: 0 };
      let stateStat = null;
      try {
        stateStat = fs.statSync(stateFile);
        entry.state = JSON.parse(fs.readFileSync(stateFile, 'utf8'));
        entry.failCount = 0;
      } catch {
        entry.failCount += 1;
      }
      cache.set(shipDir, entry);
      const timeline = parseHistory(entry.state?.history);
      const docs = listDocs(shipDir);
      const mtimes = docs.map((d) => d.mtimeMs);
      if (stateStat) mtimes.push(stateStat.mtimeMs);
      return {
        state: entry.state,
        timeline,
        docs,
        lastActivityMs: mtimes.length ? Math.max(...mtimes) : null,
        birthIso: timeline.find((t) => t.at)?.at
          ?? (stateStat ? stateStat.birthtime.toISOString() : null),
        failCount: entry.failCount,
        broken: entry.state === null && entry.failCount >= FAIL_LIMIT,
      };
    },
  };
}

import fs from 'node:fs';
import path from 'node:path';
import { gitP } from '../scan.js';

function headMtime(worktreePath) {
  try {
    const gitPath = path.join(worktreePath, '.git');
    const stat = fs.statSync(gitPath);
    if (stat.isDirectory()) return fs.statSync(path.join(gitPath, 'HEAD')).mtimeMs;
    const gitdir = fs.readFileSync(gitPath, 'utf8').trim().replace('gitdir: ', '');
    return fs.statSync(path.join(gitdir, 'HEAD')).mtimeMs;
  } catch {
    return 0;
  }
}

async function fetchDetail(repo, wt) {
  const [status, log, counts] = await Promise.all([
    gitP(['status', '--porcelain'], wt.path),
    gitP(['log', '-1', '--format=%ct\t%s'], wt.path),
    gitP(['rev-list', '--left-right', '--count', `origin/${repo.defaultBranch}...HEAD`], wt.path),
  ]);
  const [behind, ahead] = counts ? counts.split('\t').map(Number) : [null, null];
  return {
    dirtyFiles: status === null ? null : (status ? status.split('\n').length : 0),
    lastCommitTs: log ? Number(log.split('\t')[0]) * 1000 : null,
    lastCommitSubject: log ? log.split('\t').slice(1).join('\t') : null,
    aheadBehind: counts ? { ahead, behind } : null,
  };
}

export function createBranchCollector() {
  const cache = new Map(); // worktree path -> { key: headMtime, detail }
  return {
    async collect(repos, { budget = 8 } = {}) {
      const cards = [];
      let spent = 0;
      for (const repo of repos) {
        for (const wt of repo.worktrees) {
          if (!wt.branch || wt.branch === repo.defaultBranch) continue;
          const key = headMtime(wt.path);
          let cached = cache.get(wt.path);
          let pending = false;
          if (!cached || cached.key !== key) {
            if (spent < budget) {
              cached = { key, detail: await fetchDetail(repo, wt) };
              cache.set(wt.path, cached);
              spent += 1;
            } else {
              pending = true;
            }
          }
          cards.push({ repoKey: repo.key, repoName: repo.name, branch: wt.branch,
            path: wt.path, pending, ...(cached?.detail ?? {
              dirtyFiles: null, lastCommitTs: null, lastCommitSubject: null, aheadBehind: null }) });
        }
      }
      return cards;
    },
  };
}

import fs from 'node:fs';
import path from 'node:path';

export function createSessionCollector() {
  const cwdCache = new Map(); // project dir -> cwd
  return {
    collect(projectsDir) {
      let dirs = [];
      try { dirs = fs.readdirSync(projectsDir, { withFileTypes: true }); } catch { return []; }
      const out = [];
      for (const d of dirs) {
        if (!d.isDirectory()) continue;
        const dir = path.join(projectsDir, d.name);
        let newest = null;
        try {
          for (const f of fs.readdirSync(dir)) {
            if (!f.endsWith('.jsonl')) continue;
            const st = fs.statSync(path.join(dir, f));
            if (!newest || st.mtimeMs > newest.mtimeMs) newest = { file: path.join(dir, f), mtimeMs: st.mtimeMs };
          }
        } catch { continue; }
        if (!newest) continue;
        let cwd = cwdCache.get(dir);
        if (!cwd) {
          try {
            const firstLine = fs.readFileSync(newest.file, 'utf8').split('\n', 1)[0];
            cwd = JSON.parse(firstLine).cwd;
            if (cwd) cwdCache.set(dir, cwd);
          } catch { continue; }
        }
        if (cwd) out.push({ cwd, lastActiveAt: newest.mtimeMs });
      }
      return out;
    },
  };
}

import { execFile } from 'node:child_process';

export function defaultExecFileP(cmd, args, opts = {}) {
  return new Promise((resolve, reject) => {
    execFile(cmd, args, { timeout: 15000, maxBuffer: 8 * 1024 * 1024, ...opts },
      (err, stdout) => (err ? reject(err) : resolve({ stdout: stdout.toString() })));
  });
}

const FAIL_CONCLUSIONS = new Set(['FAILURE', 'ERROR', 'TIMED_OUT', 'CANCELLED']);

function rollupChecks(rollup) {
  const checks = { pass: 0, fail: 0, pending: 0 };
  for (const c of rollup ?? []) {
    const concl = (c.conclusion ?? '').toUpperCase();
    if (concl === 'SUCCESS') checks.pass += 1;
    else if (FAIL_CONCLUSIONS.has(concl)) checks.fail += 1;
    else checks.pending += 1;
  }
  return checks;
}

export function createGhClient({ execFileP = defaultExecFileP } = {}) {
  const call = async (args, cwd) => {
    try {
      const { stdout } = await execFileP('gh', args, { cwd });
      return { ok: true, stdout };
    } catch (err) {
      return { ok: false, reason: err.message };
    }
  };
  return {
    async authStatus() {
      const r = await call(['auth', 'status']);
      return r.ok ? { ok: true } : { ok: false, reason: 'gh not authenticated' };
    },
    async listOpenPrs(repoPath) {
      const r = await call(['pr', 'list', '--author', '@me', '--state', 'open',
        '--json', 'number,title,url,headRefName,isDraft'], repoPath);
      if (!r.ok) return r;
      try { return { ok: true, prs: JSON.parse(r.stdout) }; }
      catch (err) { return { ok: false, reason: err.message }; }
    },
    async prDetail(repoPath, number) {
      const r = await call(['pr', 'view', String(number),
        '--json', 'state,url,isDraft,reviewDecision,statusCheckRollup'], repoPath);
      if (!r.ok) return r;
      try {
        const raw = JSON.parse(r.stdout);
        return { ok: true, pr: { state: raw.state, url: raw.url, isDraft: raw.isDraft,
          reviewDecision: raw.reviewDecision ?? null,
          checks: rollupChecks(raw.statusCheckRollup), fetchedAt: Date.now() } };
      } catch (err) { return { ok: false, reason: err.message }; }
    },
    async prState(repoPath, number) {
      const r = await call(['pr', 'view', String(number), '--json', 'state,mergedAt'], repoPath);
      if (!r.ok) return r;
      try { const raw = JSON.parse(r.stdout); return { ok: true, state: raw.state, mergedAt: raw.mergedAt ?? null }; }
      catch (err) { return { ok: false, reason: err.message }; }
    },
  };
}

const QUERY = `
query MyIssues($after: String, $first: Int!) {
  viewer {
    assignedIssues(
      first: $first, after: $after,
      filter: { state: { type: { in: ["unstarted", "started"] } } }
    ) {
      nodes { identifier title url branchName state { name type } }
      pageInfo { endCursor hasNextPage }
    }
  }
}`;

export const linearProvider = {
  name: 'linear',
  issueUrl(trackerCfg, identifier) {
    return `https://linear.app/${trackerCfg.workspace}/issue/${identifier}`;
  },
  async listMyOpenIssues(trackerCfg, { fetchImpl = fetch, apiKey = process.env.LINEAR_API_KEY } = {}) {
    if (!apiKey) return { ok: false, reason: 'LINEAR_API_KEY not set' };
    const cap = trackerCfg.cap ?? 50;
    const issues = [];
    let after = null;
    try {
      while (issues.length < cap) {
        const res = await fetchImpl('https://api.linear.app/graphql', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json', Authorization: apiKey },
          body: JSON.stringify({ query: QUERY, variables: { after, first: Math.min(50, cap) } }),
        });
        const body = await res.json();
        if (body.errors?.length) return { ok: false, reason: body.errors[0].message };
        const page = body.data.viewer.assignedIssues;
        for (const n of page.nodes) {
          if (issues.length >= cap) break;
          issues.push({ identifier: n.identifier, title: n.title, url: n.url,
            branchName: n.branchName ?? null, state: n.state.name, stateType: n.state.type });
        }
        if (!page.pageInfo.hasNextPage) break;
        after = page.pageInfo.endCursor;
      }
      return { ok: true, issues };
    } catch (err) {
      return { ok: false, reason: err.message };
    }
  },
};

import { runId, extractTicket } from './ids.js';

function ignored(flow, patterns) {
  for (const p of patterns ?? []) {
    const [repoPart, branchGlob] = p.split('#');
    if (flow.repo.key !== repoPart && flow.repo.name !== repoPart) continue;
    if (!branchGlob) return true;
    const re = new RegExp('^' + branchGlob.replace(/[.+^${}()|[\]\\]/g, '\\$&').replace(/\*/g, '.*') + '$');
    if (flow.branch && re.test(flow.branch)) return true;
  }
  return false;
}

function taskMatchesBranch(task, branch, prTitle) {
  if (!branch && !prTitle) return false;
  const ticket = extractTicket(branch) ?? extractTicket(prTitle);
  if (ticket && ticket === task.identifier.toUpperCase()) return true;
  return task.branchName != null && task.branchName === branch;
}

export function buildFlows({ shipRuns, branchCards, prs, tasks, sessions, now, config }) {
  const flows = [];
  const claimedBranches = new Set(); // `${repoKey}\n${branch}`
  const bkey = (repoKey, branch) => `${repoKey}\n${branch}`;

  for (const run of shipRuns) {
    const flow = {
      id: runId({ repoKey: run.repoKey, branch: run.branch, birthIso: run.birthIso ?? '' }),
      kind: 'ship', title: run.state?.slug ?? run.branch,
      repo: { key: run.repoKey, name: run.repoName }, branch: run.branch,
      sources: ['ship'], state: run.state, timeline: run.timeline, docs: run.docs,
      worktree: run.worktree, pr: null, task: null, session: null,
      lastActivityMs: run.lastActivityMs, broken: run.broken, sameTicketAs: null,
    };
    claimedBranches.add(bkey(run.repoKey, run.branch));
    flows.push(flow);
  }

  for (const pr of prs) {
    const owner = flows.find((f) => f.kind === 'ship' && f.repo.key === pr.repoKey
      && (f.branch === pr.headRefName || f.state?.pr === pr.number));
    if (owner) { owner.pr = pr; owner.sources.push('pr'); claimedBranches.add(bkey(pr.repoKey, pr.headRefName)); continue; }
    claimedBranches.add(bkey(pr.repoKey, pr.headRefName));
    flows.push({ id: `pr:${pr.repoKey}#${pr.number}`, kind: 'pr', title: pr.title,
      repo: { key: pr.repoKey, name: pr.repoName ?? pr.repoKey.split('/').pop() },
      branch: pr.headRefName, sources: ['pr', 'branch'], state: null, timeline: [], docs: [],
      worktree: null, pr, task: null, session: null, lastActivityMs: null, broken: false, sameTicketAs: null });
  }

  for (const card of branchCards) {
    const key = bkey(card.repoKey, card.branch);
    const owner = flows.find((f) => f.repo.key === card.repoKey && f.branch === card.branch);
    if (owner) {
      if (!owner.sources.includes('branch')) owner.sources.push('branch');
      owner.git = card;
      owner.worktree ??= card.path;
      owner.lastActivityMs = Math.max(owner.lastActivityMs ?? 0, card.lastCommitTs ?? 0) || owner.lastActivityMs;
      continue;
    }
    if (claimedBranches.has(key)) continue;
    flows.push({ id: `branch:${card.repoKey}#${card.branch}`, kind: 'branch', title: card.branch,
      repo: { key: card.repoKey, name: card.repoName }, branch: card.branch, sources: ['branch'],
      state: null, timeline: [], docs: [], worktree: card.path, git: card, pr: null, task: null,
      session: null, lastActivityMs: card.lastCommitTs, broken: false, sameTicketAs: null });
  }

  for (const task of tasks) {
    const candidates = flows.filter((f) => f.kind !== 'task'
      && taskMatchesBranch(task, f.branch, f.pr?.title));
    const rank = (f) => (f.kind === 'ship' ? 3 : f.pr ? 2 : 1) * 1e15 + (f.lastActivityMs ?? 0);
    candidates.sort((a, b) => rank(b) - rank(a));
    if (candidates.length) {
      candidates[0].task = task;
      candidates[0].sources.push('task');
      for (const loser of candidates.slice(1)) loser.sameTicketAs = task.identifier;
    } else {
      flows.push({ id: `task:${task.identifier}`, kind: 'task', title: task.title,
        repo: { key: null, name: null }, branch: null, sources: ['task'], state: null,
        timeline: [], docs: [], worktree: null, pr: null, task, session: null,
        lastActivityMs: null, broken: false, sameTicketAs: null });
    }
  }

  for (const session of sessions) {
    const owner = flows.find((f) => f.worktree === session.cwd);
    if (owner) {
      owner.session = session;
      owner.sources.push('session');
      owner.lastActivityMs = Math.max(owner.lastActivityMs ?? 0, session.lastActiveAt);
    }
    // Standalone session cards are created by the engine only for repos with no flows at all.
  }

  return flows
    .filter((f) => !ignored(f, config.ignore))
    .map((f) => classify(f, { now, config }));
}
```

const GATE_ACTION = { scope: 'answer-questions', plan: 'approve-plan' };
const AGENT_PHASES = new Set(['plan-approved', 'implement', 'polish', 'qa']);

export function classify(flow, { now, config }) {
  const thresholdMs = (config.activityThresholdMinutes ?? 10) * 60_000;
  const recent = flow.lastActivityMs != null && now - flow.lastActivityMs < thresholdMs;
  const set = (group, action = null, statusLine = '') =>
    Object.assign(flow, { group, action, statusLine,
      waitingSince: flow.lastActivityMs ?? flow.git?.lastCommitTs ?? null });

  if (flow.broken) return set('failing', null, 'state.json unreadable — check the run');

  if (flow.kind === 'ship') {
    const phase = flow.state?.phase;
    const qaFailed = flow.timeline.some((t) => /fail/i.test(t.note ?? '') && (t.phase === 'qa' || /qa/i.test(t.note ?? '')));
    if (phase === 'merged' || phase === 'verified') return set('shipped', null, phase);
    if (phase === 'ready-to-merge') return set('needsYou', 'merge', 'ready to merge');
    if (phase in GATE_DOC) {
      const gateReady = flow.docs.some((d) => d.name === GATE_DOC[phase]);
      if (gateReady && !recent) return set('needsYou', GATE_ACTION[phase], `waiting: ${GATE_ACTION[phase].replace('-', ' ')}`);
      return set('active', null, `agent working: ${phase}`);
    }
    if (AGENT_PHASES.has(phase)) {
      if (qaFailed && !recent) return set('failing', null, 'QA reported failure');
      if (recent) return set('active', null, `agent working: ${phase}`);
      return set('failing', null, `run stalled mid-${phase}`);
    }
    return set('active', null, phase ?? 'unknown phase');
  }

  if (flow.kind === 'pr') {
    const checks = flow.pr?.detail?.checks;
    if (checks && checks.fail > 0) return set('failing', null, `CI failing (${checks.fail})`);
    return set('active', null, 'open PR');
  }

  if (flow.kind === 'task') return set('notStarted', null, flow.task?.state ?? 'not started');

  // branch / session ambient cards
  const idleMs = now - (flow.lastActivityMs ?? 0);
  if (flow.lastActivityMs == null || idleMs > STALE_BRANCH_MS) return set('stale', null, 'no recent activity');
  return set('active', null, 'local work');
}

import fs from 'node:fs';
import path from 'node:path';

export function snapshotRun({ shipDir, runId, meta }, historyDir) {
  const dest = path.join(historyDir, runId);
  const tmp = path.join(historyDir, `.tmp-${runId}`);
  fs.rmSync(tmp, { recursive: true, force: true });
  fs.mkdirSync(tmp, { recursive: true });
  fs.cpSync(shipDir, path.join(tmp, 'ship'), { recursive: true });

  const metaFile = path.join(dest, 'meta.json');
  let existing = {};
  try { existing = JSON.parse(fs.readFileSync(metaFile, 'utf8')); } catch { /* first snapshot */ }
  const merged = { ...existing };
  for (const [k, v] of Object.entries(meta)) {
    if (v != null && merged[k] == null) merged[k] = v;
  }
  merged.pinnedAt ??= new Date().toISOString();
  fs.writeFileSync(path.join(tmp, 'meta.json'), JSON.stringify(merged, null, 2));

  fs.rmSync(dest, { recursive: true, force: true });
  fs.renameSync(tmp, dest);
}

export function listArchived(historyDir) {
  let entries = [];
  try { entries = fs.readdirSync(historyDir, { withFileTypes: true }); } catch { return []; }
  const out = [];
  for (const e of entries) {
    if (!e.isDirectory() || e.name.startsWith('.tmp-')) continue;
    const dir = path.join(historyDir, e.name);
    try {
      out.push({ runId: e.name, dir, meta: JSON.parse(fs.readFileSync(path.join(dir, 'meta.json'), 'utf8')) });
    } catch { /* torn entry — skip */ }
  }
  return out;
}

const FATE_BY_STATE = { MERGED: 'merged', CLOSED: 'abandoned' };

export async function resolveFates(historyDir, liveRunIds, ghClient) {
  for (const entry of listArchived(historyDir)) {
    if (liveRunIds.has(entry.runId) || entry.meta.fate || entry.meta.pr == null || !entry.meta.repoPath) continue;
    const r = await ghClient.prState(entry.meta.repoPath, entry.meta.pr);
    if (!r.ok) continue; // retry next cycle; never persist a guess
    entry.meta.fate = FATE_BY_STATE[r.state] ?? 'unknown';
    if (r.mergedAt) entry.meta.mergedAt = r.mergedAt;
    fs.writeFileSync(path.join(entry.dir, 'meta.json'), JSON.stringify(entry.meta, null, 2));
  }
}

export function prune(historyDir, { maxEntries, maxAgeDays }) {
  const entries = listArchived(historyDir)
    .sort((a, b) => Date.parse(b.meta.pinnedAt ?? 0) - Date.parse(a.meta.pinnedAt ?? 0));
  const cutoff = Date.now() - maxAgeDays * 86_400_000;
  entries.forEach((entry, i) => {
    if (i >= maxEntries || Date.parse(entry.meta.pinnedAt ?? 0) < cutoff) {
      fs.rmSync(entry.dir, { recursive: true, force: true });
    }
  });
}
```

  res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
  return res.end(html);
}
if (req.method === 'GET' && url.pathname === '/api/health') return json(res, 200, { name: 'shipyard', version });
if (req.method === 'GET' && url.pathname === '/api/flows') return json(res, 200, engine.getSnapshot());
if (req.method === 'GET' && url.pathname === '/api/flow') {
  const flow = await engine.flowDetail(url.searchParams.get('id'));
  return flow ? json(res, 200, flow) : json(res, 404, { error: 'unknown flow' });
}
if (req.method === 'GET' && url.pathname === '/api/doc') {
  const abs = engine.docPath(url.searchParams.get('flow'), url.searchParams.get('file') ?? '');
  if (!abs) return json(res, 404, { error: 'not found' });
  return json(res, 200, { file: abs, content: fs.readFileSync(abs, 'utf8') });
}
if (req.method === 'POST' && url.pathname === '/api/open') {
  const body = await readBody(req);
  const abs = engine.openTarget(body.flow, body.file ?? '.');
  if (!abs) return json(res, 404, { error: 'not found' });
  return json(res, 200, { opened: abs, ok: await engine.openInEditor(abs) });
}
if (req.method === 'POST' && url.pathname === '/api/refresh') { await engine.refreshNetwork(); return json(res, 200, { ok: true }); }
if (req.method === 'POST' && url.pathname === '/api/config') {
  return json(res, 200, { saved: saveUserConfig(await readBody(req), {}) });
}
```

- [ ] **Step 1: Implement the launcher**

`bin/shipyard`:

```js
#!/usr/bin/env node
import fs from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { execFile } from 'node:child_process';
import { loadConfig } from '../lib/config.js';
import { createEngine } from '../lib/engine.js';
import { createServer, startServer } from '../server.js';
import { createToken } from '../lib/security.js';

const args = process.argv.slice(2);
const portFlag = args.includes('--port') ? Number(args[args.indexOf('--port') + 1]) : null;
const { config, created, missingRoots } = loadConfig({});
const port = portFlag ?? config.port;

async function existingInstance(port) {
  try {
    const res = await fetch(`http://127.0.0.1:${port}/api/health`, { signal: AbortSignal.timeout(1000) });
    const body = await res.json();
    return body.name === 'shipyard';
  } catch { return false; }
}

function openBrowser(url) {
  const cmd = process.platform === 'darwin' ? 'open' : 'xdg-open';
  execFile(cmd, [url], () => {});
}

if (await existingInstance(port)) {
  console.log(`shipyard already running at http://127.0.0.1:${port} — opening it`);
  openBrowser(`http://127.0.0.1:${port}`);
  process.exit(0);
}

const token = createToken();
const engine = createEngine({ config, setup: { created, missingRoots, roots: config.roots } });
const server = createServer({ token, version: '0.1.0', engine, config });
let bound;
try { bound = await startServer(server, port); }
catch { bound = await startServer(server, 0); } // port taken by something else
engine.start();
// Archiver pidfile: snapshots are idempotent, so a second writer is wasteful, not
// corrupting — record who owns archiving and clean up on exit.
const pidFile = path.join(os.homedir(), '.claude', 'shipyard', 'archiver.pid');
fs.mkdirSync(path.dirname(pidFile), { recursive: true });
fs.writeFileSync(pidFile, String(process.pid));
process.on('exit', () => { try { fs.rmSync(pidFile); } catch {} });
const url = `http://127.0.0.1:${bound}`;
console.log(`shipyard: ${url}`);
if (created) console.log('first run — confirm scan roots in the setup panel');
openBrowser(url);
```
